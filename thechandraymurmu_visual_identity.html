03 / Logo

Logo System

Three concept directions — all rooted in the same friendly, technical identity. Choose one as primary and adapt the others as variants.

thechandraymurmu

Option A — Wordmark

Full name as the mark. Accent color highlights the core "chandray" to create rhythm and recognition. Use for website headers and long-form contexts.

C
chandraymurmu dev · design · open source

Option B — Combo Mark ★ Recommended

Icon + wordmark. The gradient "C" mark is versatile for favicons, avatars, and app icons. Best for most use cases — marketing, social, website.

C

Option C — Icon Only

Standalone mark for small contexts — favicon, GitHub avatar, social profile photo. Use only when the full name isn't needed.

✓ Logo Do's
  • Use on brand-approved backgrounds (navy, white, light blue)
  • Maintain clear space of at least 1× the icon height on all sides
  • Use the teal accent consistently on the same letterform
✗ Logo Don'ts
  • Don't stretch, rotate, or distort the logo
  • Don't place on busy photo backgrounds without an overlay
  • Don't change the font or use alternate typefaces for the wordmark

07 / Rules

Brand Do's & Don'ts

Three rules in each direction to keep the brand consistent across every touchpoint.

✓ Always Do
  • Lead with the human — write to one person, not a crowd. Use "you" and "I", not "clients" and "users".
  • Use white space generously. The brand breathes. Don't cram content.
  • Apply the gradient accent (blue → teal) to meaningful moments — the logo mark, a key CTA, an open-source tag. Not everywhere.
  • Keep tech readable. If you use a technical term, follow it with a plain-language explanation.
  • Maintain the serif/sans pairing. DM Serif for feeling. Jakarta Sans for clarity. Always both.
✗ Never Do
  • Don't use more than 2 brand colors in a single small UI element. Restraint is the point.
  • Don't use agency-speak — "synergy", "leverage", "scalable solutions". This brand is a person, not a firm.
  • Don't put dark text on the dark navy background without sufficient contrast (minimum WCAG AA: 4.5:1).
  • Don't mix the logo wordmark with a different typeface, even "just for a post."
  • Don't use the full color palette on social graphics — pick 2 colors max per post for visual consistency.
